# Supported Languages

`system-releaser` automatically detects, tests, and builds software written in 23 different programming languages. 

## Language Support Matrix

| Language | Detection File(s) | Default Build Tool | Build Command | Test Command |
|----------|-------------------|--------------------|---------------|--------------|
| **Rust** | `Cargo.toml` | Cargo | `cargo build --release` | `cargo test` |
| **Go** | `go.mod` | Go | `go build` | `go test ./...` |
| **Node.js** | `package.json` | npm / yarn | `npm run build` | `npm test` |
| **TypeScript** | `tsconfig.json` | tsc | `tsc` | `npm test` |
| **Python** | `pyproject.toml` | Python / pip | `python -m build` | `pytest` |
| **Ruby** | `Gemfile` | Bundler | `gem build` | `rake test` |
| **Java** | `pom.xml` | Maven | `mvn package` | `mvn test` |
| **Kotlin** | `build.gradle.kts` | Gradle | `gradle build` | `gradle test` |
| **Scala** | `build.sbt` | sbt | `sbt compile` | `sbt test` |
| **C++** | `CMakeLists.txt` | CMake | `cmake --build .` | `ctest` |
| **C** | `Makefile` | Make | `make` | `make test` |
| **C#** | `*.csproj` | dotnet | `dotnet build -c Release` | `dotnet test` |
| **F#** | `*.fsproj` | dotnet | `dotnet build -c Release` | `dotnet test` |

| **PHP** | `composer.json` | Composer | `composer install` | `phpunit` |
| **Perl** | `Makefile.PL` | Make | `make` | `make test` |

| **Zig** | `build.zig` | Zig | `zig build -Doptimize=ReleaseSafe`| `zig build test` |

## Cross-Compilation

Native cross-compilation is fully supported for languages that emit standalone binaries (like Rust, Go, C/C++, and Zig). `system-releaser` will automatically configure the appropriate target triples and environment variables (e.g., `GOOS`/`GOARCH` for Go) based on your `releaser.yaml` config.

For interpreted or bytecode languages (like Python, Node.js, Java), `system-releaser` focuses on packaging the source or bytecode into universal archives and generating runtime wrappers.

<Callout type="info">
  **Want to add a new language?**

</Callout>
