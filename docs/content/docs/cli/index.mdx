# CLI Reference

`system-releaser` is a comprehensive Rust-based CLI tool designed to automate the entire release pipeline across 23 programming languages.

## Global Options

The following global options apply to all commands:

- `--project-dir <DIR>`: Specify the project directory (default: `.`)
- `--verbose`, `-v`: Enable verbose output for debugging
- `--help`, `-h`: Display help information for any command
- `--version`, `-V`: Display the current CLI version

## Typical Workflow

The standard release workflow follows a linear pipeline:

<Steps>
  <Step>
    **Detect**: Run `releaser detect` to identify your language and build system.
  </Step>
  <Step>
    **Initialize**: Run `releaser init` to generate a `releaser.yaml` configuration file.
  </Step>
  <Step>
    **Validate**: Run `releaser check` to ensure your environment is ready.
  </Step>
  <Step>
    **Test**: Run `releaser test` to execute your test suites.
  </Step>
  <Step>
    **Release**: Run `releaser release` to build, package, and publish.
  </Step>
</Steps>
