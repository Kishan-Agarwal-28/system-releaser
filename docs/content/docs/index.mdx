**system-releaser** is an opinionated, security-hardened project detection, cross-platform build, and multi-package-manager release engine written in Rust.

With zero or minimal configuration, `system-releaser` inspects your project directory, detects the programming language and existing manifests, executes your native test suites, bumps semantic versions, compiles cross-platform binaries, generates universal one-liner installer scripts (`curl | sh` and `irm | iex`), and builds production-ready manifests across **14 system package managers** and **23 programming languages**.

## Why system-releaser?

Maintaining software release pipelines across multiple operating systems and distribution channels is traditionally complex:
- Different package managers require distinct manifest syntaxes (YAML, JSON, Ruby DSL, Bash scripts, RPM Spec, TCL Portfiles).
- Installing binaries requires writing custom OS-specific shell scripts that handle architecture detection and checksum integrity.
- Cross-platform paths, non-UTF-8 characters, and monorepos often break ad-hoc release scripts.

`system-releaser` solves this by providing a single, reliable CLI tool that manages the entire lifecycle: **Detect → Verify → Test → Build → Package → Sign → Distribute**.
